# 交接任务：仅修正 STM32 下位机固件的 5 个极性参数

## 前置条件

用户必须先提供 5 个明确的实测数字。每个值只能是 `1` 或 `-1`：

- `FW_MOTOR_LEFT_POLARITY = <实测值>`
- `FW_MOTOR_RIGHT_POLARITY = <实测值>`
- `FW_ENCODER_LEFT_POLARITY = <实测值>`
- `FW_ENCODER_RIGHT_POLARITY = <实测值>`
- `FW_GYRO_Z_POLARITY = <实测值>`

如果仍有 `<实测值>`、`1 或 -1` 或缺失值，立即停止，不得猜测、不修改文件。

## 唯一允许修改的文件

`下位机源码/STM32-car/User/board_config.h`

只修改 production 配置区中这 5 个宏的定义。不要修改 `#ifdef FW_APP_HOST_TEST` 区域、注释、格式或其它任何文件。

## 严格要求

1. 只改这 5 个宏，其他参数必须保持原样：轮径、轮距、编码器、死区、速度、停车阈值、舵机参数、verified 标志等均不得修改。
2. 左右电机极性必须分别按左右轮实物方向填写，不能因为一侧为 `1` 就把另一侧也改成 `1`。
3. 不得根据源代码默认值、日志猜测，必须使用用户明确提供的实测值。
4. 修改后检查 diff，确认只有这 5 行的数值发生变化。
5. 不要顺便重构、格式化、编译、烧录或修改测试契约。

## 交付报告

报告以下内容：

- 修改的完整文件路径；
- 每个参数的旧值 → 新值；
- diff 是否确认只有这 5 个值改变；
- 如果实测值不完整，明确报告“未修改”。
